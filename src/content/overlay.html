Overlay is a mobile app scaffold I built around a single idea: a full-screen, pannable map that flies to your current location the moment the app opens. It's the foundation I use to kick off location-based app ideas without re-solving the same setup every time—permissions, a live location "puck," and a map that actually feels native rather than embedded.

It's built with Expo and Mapbox GL via @rnmapbox/maps, using expo-location for permissions and positioning. Because it relies on native Mapbox modules, it ships as a custom Expo dev client rather than running in Expo Go. The app is backed by a Fastify API on Cloud Run, with infrastructure (Cloud Run, Cloud SQL, Storage, Artifact Registry) provisioned via Terraform.
